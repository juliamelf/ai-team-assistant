# ИИ-ассистент руководителя ИТ-команды

Учебно-практический проект: ИИ-решения для управления ИТ-командой — от анализа процесса и архитектуры до прототипа и оценки качества на размеченных данных.

**Статус: в разработке.** Результаты и метрики появятся в этом README только после оценки на достаточном объёме данных.

## Что разрабатывается

| Модуль | Что делает | Статус |
|---|---|---|
| Протокол встреч 1:1 | Голосовое сообщение в Telegram → распознавание речи → выжимка задач, договорённостей и запросов на развитие → подтверждение руководителем | Прототип собран, готовится размеченный датасет для оценки |
| Матрица компетенций | Генерация матрицы под должность и стек проекта на основе профстандарта (RAG) с утверждением человеком | В разработке |
| Профиль вакансии и тестовое задание | Профиль вакансии по матрице; тестовое задание с проверкой решения LLM-судьёй | В разработке |
| ИПР | GAP-анализ по матрице и план развития с вехами | В разработке |

## Стек

- Оркестрация: n8n
- Распознавание речи: GigaAM
- LLM: GigaChat
- Данные: PostgreSQL (+ pgvector — для RAG)
- Инфраструктура: Docker, облако Amvera

## Структура репозитория

```
docs/            архитектура, решения, отчёты об оценке качества
n8n/workflows/   экспортированные сценарии n8n (без секретов)
src/             скрипты на Python: индексация, поиск, вспомогательные утилиты
evals/           датасеты для оценки (без персональных данных) и скрипты прогона
data/            локальные исходные данные — в репозиторий не попадают
```

## Безопасность и данные

- Ключи API, токены и пароли хранятся только в переменных окружения. Шаблон — в `.env.example`; файл `.env` в репозиторий не попадает.
- В репозитории только вымышленные данные: тестовая команда «ТестЛаб» и синтетические записи встреч. Реальных персональных данных здесь нет.
- Перед экспортом сценария n8n в `n8n/workflows/` он проверяется на отсутствие ключей и токенов в тексте.
