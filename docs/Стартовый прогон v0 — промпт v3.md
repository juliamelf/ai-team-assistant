## Ошибки v3 по навыкам (11)

- **Навык из планов — 4:** «пройдёт курс», «будет писать», «будет оценивать», «хочет участвовать в архитектуре» (записи 1, 8, 10).
- **Додуманные детали — 3:** «Нагрузочное тестирование (k6, JMeter)» в записях 2 и 5 и «Автоматизация на Python (pytest)» в записи 9 — этих инструментов в речи нет. Название одинаковое во всех записях, вероятно, взято из списка навыков в промпте v3; для руководителя оно всё равно читается как факт о сотруднике.
- **Неверная тема — 2:** регрессионное тестирование вместо регрессионной модели (запись 3); анализ логов записан как документирование дефектов (запись 4).
- **Навык из задачи — 1:** «профиль нагрузки готов» (запись 10) — выполненная задача, а не оценка уровня.

**Как сравнивать с v4.** Навык засчитывается по теме. Направление (same / up / down) и оценка (strong / weak) в F-меру не входят: у v3 их нет. Для v4 они считаются отдельной метрикой — доля верных среди TP. В схеме 1.0 у навыка нет свободного названия — только `skill_id` и цитата, а название бот берёт из словаря тем. Поэтому ошибка «додуманные детали» в навыках у v4 повториться не может; её стоит проверять в задачах, наблюдениях и сигналах.

**Статусы задач у v4.** Чтобы модель могла сослаться на старую задачу, в контекст передаётся список открытых задач с короткими ID (T и номер). В оценочном прогоне задачи записей 1–9 должны быть подтверждены в базе до прогона записи 10 — иначе списка не будет. Порядок прогона: записи по дате встречи, каждая выжимка подтверждается по эталону перед следующей.

Переразметка — черновик Claude, основной разметчик — вы. Новые колонки листа «Эталон»: тема, направление, оценка, тип и тон сигнала, тип срока, `value`, `value_to`, заметка, статус задачи, ссылка на задачу.

- **Навыки (24 пункта):** 14 — same / strong, 5 — same / weak, 5 — up. Направление `up` поставлено только там, где в речи есть слова об изменении («прогресс есть», «уже получше», «первый автотест», «пройдено 70%»).

Исходные уровни заполняются в задаче «Матрица компетенций в базе» (21.11); до неё события по навыкам копятся, но в изменение уровня не превращаются. Изменение уровня подтверждает руководитель.
- **Статусы задач (5 пунктов):** см. раздел выше. Дубль 10-S1 удалён.
- **06-R1 «Отказалась от психологического теста»** — тон `neutral` (решение 14.11.2026).
