Контракт выжимки встречи `schema_version` 1.0 (JSON Schema 2020-12). По нему n8n проверяет ответ модели, а `app.save_summary` в базе дублирует те же правила и проверяет ID по справочникам.

Проверка схемы после каждой правки: `python3 schema/check_schema.py schema/summary_schema_1.0.json` — должно быть «расхождений 0». Решения по схеме — `docs/Схема выжимки 1.0 — решения и правки.md`.
